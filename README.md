### 프로그램 소개
<img width="959" height="437" alt="스크린샷 2026-10-30 161907" src="https://github.com/user-attachments/assets/f2131403-d533-4ab8-a575-dfb79bf6dd23" />

1. 프로젝트를 생성합니다.
2. 해당 프로젝트에서 사용하는 이미지 폴더/파일을 업로드합니다.
3. yolo pose로 자동 분석을 시작합니다.

   
<img width="932" height="815" alt="스크린샷 2026-10-30 161951" src="https://github.com/user-attachments/assets/abb84282-154f-4bb8-bc71-9dc287462659" />

5. 자동분석 이후 검수 단계로 넘어갑니다.
6. 검수 완료된 것은 Train, Validation, Test 비율을 지정해 이미지와 라벨파일로 내보내기 할 수 있습니다.
